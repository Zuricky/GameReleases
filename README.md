# GameReleasesBot — by Zuricky

Bot Discord che mostra automaticamente le **uscite videoludiche più importanti** dei prossimi 3 mesi usando la RAWG API.

## Funzionalità

- 🎮 Mostra **TOP 10 giochi importanti**
- 🔄 Aggiornamento automatico ogni **2 ore**
- 📝 I messaggi non vengono reinviati → **si aggiornano** senza spam
- 🟦 Embed con immagine grande, data, generi, piattaforme
- 🛒 Link diretto allo store migliore:
  - Steam
  - Epic Games Store
  - GOG
  - Fallback RAWG

## Comandi

- `/setchannel` → imposta il canale delle notifiche
- `/checknow` → forza aggiornamento
- `/nextreleases` → mostra manualmente le prossime uscite
